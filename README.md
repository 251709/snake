# Змейка

## Описание проекта

Проект представляет собой реализацию классической аркадной игры «Змейка» на языке Python с использованием библиотеки Pygame.

Цель игры — управлять движением змейки, собирать еду, увеличивать её длину и набирать максимальное количество очков, избегая столкновений со стенами и собственным телом.

## Основные возможности

- Управление змейкой с помощью клавиатуры.
- Автоматическое движение змейки.
- Генерация еды в случайных свободных клетках.
- Увеличение длины змейки при сборе еды.
- Обнаружение столкновений.
- Подсчёт набранных очков.
- Возможность перезапуска игры.
- Пауза и изменение скорости движения.
- Сохранение лучшего результата.
